方案一 · 适配现有 OCS 网课助手

OCS 题库配置

复制下方完整 JSON 配置并粘贴到 OCS 面板的「通用 - 全局设置 - 题库配置（自定义题库）」，即可直接对 2026 工程训练全部作业实现 100% 本地匹配自动作答。

  1. 01

    复制题库配置

    点击上方「一键复制配置」按钮获取完整配置，切勿通过微信或 QQ 聊天窗口中转粘贴，避免符号转义导致 JSON 解析失败。

  2. 02

    粘贴到 OCS 全局设置

    打开智慧树课程页中的 OCS 悬浮窗，进入「通用 → 全局设置 → 题库配置 → ⋯ 自定义题库」，清空后粘贴并保存。

  3. 03

    进入作业页自动作答

    配置采用纯前端 data: 本地回显与 fetch 模式，零安全风险警告；若标准版 OCS 提示域名白名单警告，直接确认忽略即可正常作答。

方案二 · 免配置独立运行

独立智慧树自动答题脚本

不想安装和配置完整版 OCS？直接安装 EngForge 专版脚本——仅保留知到智慧树新形态作业页答题逻辑，内置直连本题库，安装即用。

精简剥离

专注智慧树新形态作业页

基于 OCS zhs.ts 的 smartExam 逻辑独立重写，移除多平台视频刷课与无关依赖，仅在 examloop.zhihuishu.com/exam/* 生效，轻巧无干扰。

开箱即用

默认直连本仓库静态题库

脚本默认拉取 mjy.js.org/nwafu-engforge-2026/data/questions.json 并本地缓存，覆盖单选、多选、判断、多空填空及全部 4 道配图题。

安全可控

自动填答，人工核对交卷

提供可拖拽悬浮控制条，支持一键整卷自动答题、单题作答、切题速度调节与随时暂停；绝不自动交卷，完成核对后再手动提交。
